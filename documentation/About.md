# RBProxy
This is the first documentation for the project...
RBProxy is a proxy made for catching "script kiddies" while monitoring every request and response for the server, the project is not mean't to make the developer ignore bugs but to make it less worst than that already is.

So the project itself excels (or wants to excel in):
 - Port adaptability
 - Create fake exploits to reach malicious people
 - Detect attacks and leaks
 - Report attacks, injection attempts and exploits with simulation
 
 It uses regex for superficial attacks but virtualization for detecting more complex attacks, every client have scores that once reached the maximum, limits rate of uses, blocks temporally or blacklist ip.
